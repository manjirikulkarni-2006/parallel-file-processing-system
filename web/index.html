Operating System Concepts Demonstrated

  • Process Management: Worker pool creation via fork() and orderly termination harvesting with waitpid() to eliminate zombie processes.
  • Inter-Process Communication (Pipes): Unidirectional pipe descriptors with poll() multiplexing, non-blocking chunk reads, and EINTR retry handling.
  • Shared Memory & Semaphores: POSIX shm_open(), mmap(), and process-shared POSIX semaphores (sem_t) for dynamic work-stealing synchronization.
  • CPU Scheduling Simulation: Accurate discrete-event modeling of FCFS, Non-preemptive Priority, and Round Robin scheduling.
  • Real-Time AI Telemetry: Sentiment lexicon scoring, regex error signature extraction, and latency anomaly detection on live dataset records.
